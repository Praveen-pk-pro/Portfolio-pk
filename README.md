## 💻 Getting Started Locally

### Prerequisites
- **Node.js** (v18 or higher recommended)
- **npm**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Praveen-pk-pro/Portfolio-pk-main.git
   cd Portfolio-pk-main
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
